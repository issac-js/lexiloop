# v129：语义复核可靠性、表达迁移小批试练与观察工具

## 用户可见变化

- 学习页区分核对服务异常与语言本身难以判断；可点击“重新核对表达”，不新增学习评分。合理同义表达仍给正向反馈，服务失败不算错。
- 补上看中文打英文题型到判分器的中文语境传递，修复替代表达直接因缺上下文退出。
- 修复兼容 API 无末尾换行时丢失最后一帧，检测长度截断；调整有界复核预算，清理旧提示缓存。没有通过泛化词根或删冠词放行所有语法。
- 练习场增加 10 组“表达联系与新情境”，每轮 3 题：过程/结果、联系、跟进、澄清、核实、报告、转介、限制、关闭、恢复。结构与对照按需查看，未收录答案不标错；结果仅在本机按账号隔离，独立于正式 FSRS/打卡。
- 本地 CSV 分析脚本按来源、卡型、辅助、间隔、日期分组，区分系统判定与自评；未知/旧口径不补造数据。观察期结束后可直接用。
- 修正 SW 预缓存仍引用旧版 focus 模块的问题，升版脚本与离线检查覆盖所有预缓存资源版本。

## 验证与发布边界

在最终 PR 和 main 提交上通过离线、实际 Chromium/WebKit 隔离 SDK 与 iOS Simulator 测试后，才可交付该 main SHA 对应的正式 CI ZIP。生产模型调用、实际网关元数据保存、物理 iPhone、生产缓存交接不由模拟测试证明。

本轮无生产模型调用、数据库迁移、既有学习历史改写或原站发布。预算调整的线上效果需要后续实际状态码和隔离模型验收；不声称所有合理表达已能自动判对。

关页持续复核尚未接通；维护端缺原应用后台管理入口，原项目只读能力检查和验收指令见 [交接文档](../BACKGROUND-REVIEW-HANDOFF.md)。此项不计入已实现。
