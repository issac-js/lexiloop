# 学习效果观察安排

## 本轮交付

v128 修正学习记录的导出与计时，为实践纠偏、巩固迁移阶段建立可核查的观察依据。

- 学习记录 CSV 保留 ID、来源、判定、提示与选项辅助标记，附带复习前状态和时间。
- 按稳定记录 ID 分页，单次最多导出最近 20000 条。导出期间新增的记录留待下次导出，切换账号会终止当前导出。
- 学习页记录读题开始至首次作答或揭晓的 response_ms，以及作答后至评分的 feedback_ms。elapsed_ms 为两者之和。
- feedback_ms 包含答案阅读、语义复核等待及自评停留。全部为墙钟时间，会包含后台停留。时钟回拨导致顺序异常时，细分时间留空。
- 新计时在 prev_state.learning_observation 中标注版本并保留作答当时的卡型。历史记录和其他练习来源标为 legacy_or_other，细分耗时留空。
- 统计页使用“平均记录用时”名称。不同来源、旧版和新版的耗时分别分析。

## 观察起点与操作

以 v128 发布后，隔离账号验证真实学习写入和导出字段完整的日期作为观察起点。先观察约 14 天，日常学习保持相对稳定。遇到误判或体验缺陷可直接修复，并在复盘时注明版本变化。

使用原有“我的 → 导出学习记录”入口。CSV 中 created_at_iso 保留时区信息，分析时统一换算上海日期。旧 date 列保持兼容，时间判断使用完整 ISO 列。

本次没有启动定时后台分析。初步报告需要读取明确范围的学习记录，届时按观察起点和实际样本确定范围。

## 初步报告的口径

1. 分别统计 recognition、production、cloze，以及不同练习来源。历史卡型仅有当前参考值时标记覆盖范围。
2. 区分有提示、借助选项和无辅助作答，缺失值为未知。历史布尔字段可能由数据库默认填充，优先使用新记录进行提示依赖分析。
3. 分开报告自评分数和系统判定。grade ≥ 3 是自评回忆结果，hit/alt 是判分结果。两者均不能单独证明跨情境掌握。
4. 按实际复习间隔观察后续回忆，标明重复作答、同日记录和数据缺口。仅有 prev_state 时不声称已还原完整历史。
5. 限定 timing_schema=study_wall_v1 后再比较学习耗时。长停留单独列出，不能解释为记忆困难。旧口径、新口径和其他来源不合并成反应速度结论。
6. 报告样本量和字段覆盖率。样本不足时延长观察，不自动调整 FSRS 参数。

## 后续训练安排

初步观察后，再从现有练习额度中安排少量新情境题，观察换句子、减少提示后的使用情况。先精修内容与判分，验证负担和体验，再决定是否扩大。新情境训练与效果报告属于后续工作，本轮只交付记录基础。

## v129：分析工具与小批迁移练习

工具已实现，无需等观察期结束再开发。导出 v128+ CSV 后，在仓库运行：

```bash
python -B tools/analyze_learning.py reviews.csv --since 2026-11-08 --until 2026-11-21 --out observation-report
```

日期只是示例，按实际发布与隔离验收完成日选择。输出目录必须是新目录，包含 JSON 和 Markdown；纯本地读取，不连接生产或模型，不包含逐条单词/作答原文。按来源、卡型、卡型可信度、辅助标记、实际间隔、日期分组；JSON 附交叉分层。重复 ID 去重；相同 ID 内容冲突则拒绝分析。时间缺失或不带时区、旧字段口径、未知提示标记都单独统计，不补造数据。

自评分数、系统判定分别汇总；只用新口径且三段耗时自洽的数据计算墙钟中位数。超过 5 分钟的记录单列，不解释为记忆困难。日历跨度不足 14 天标为初步报告；跨度满足也不代表各组样本充足或有因果证据。单次 CSV 上限 20000，报告不能证明范围外无遗漏。当前没有用户学习数据报告，也未自动调整 FSRS。

学习页语义复核原因附在既有 prev_state.learning_observation.review_reason 并追加 CSV 列，区分 pending/cached/reviewed、超时、服务不可用、空回复、截断、格式异常、语义不确定和冠词保护。历史缺失值保持未知。实际网关是否完整保留这些元数据仍需发布后隔离账号核验。

练习场新增“表达联系与新情境”：10 组精修内容，每次 3 题。先回忆，再按需查看结构与区别，最后可尝试换情境表达并看一种参考。已收录合理替代表达给正向反馈；未收录不等于错，不使用简单词义替换放行所有句子。自评/本机记录不等于跨情境掌握。训练结果按账号保存在本机，最多 60 轮，不同步、不修改 FSRS、不计正式打卡，不调用模型。建议替代一次其他练习，不作为新增每日任务。
